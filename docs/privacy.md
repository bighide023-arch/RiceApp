# プライバシーポリシー（お米相場）

最終更新日：2026年10月12日

「お米相場」（以下「本アプリ」）は、利用者の個人情報を収集しません。

## 収集する情報

本アプリは、氏名、メールアドレス、位置情報、端末の識別子、利用状況などの情報を収集・送信しません。広告や解析のための外部サービスも使っていません。

## 通信について

本アプリとウィジェットは、価格データを取得するために GitHub（raw.githubusercontent.com）上の公開データファイルを読み込みます。この通信では、利用者を特定する情報は送信しません。通信の際、GitHub が一般的なアクセス記録（IP アドレスなど）を残す場合があります。その扱いは GitHub のプライバシーポリシーに従います。

## 端末内に保存する情報

前回取得した価格データと、お気に入りに登録した銘柄は、利用者の端末内にだけ保存されます。アプリを削除すると消えます。

## データの出典

表示する価格は、農林水産省の公表データ（公共データ利用規約 第1.0版）を加工して作成したものです。今後の見通しは過去の値動きから計算した目安で、将来の価格を保証するものではありません。
